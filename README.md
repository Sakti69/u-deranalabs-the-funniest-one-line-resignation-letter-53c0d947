make.fun entry for `u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947`.

`main.ts` (Node 22, standard library only) writes one original single-line
resignation letter, in the voice of a cron job, to `/output/entry.txt`:

Run locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
